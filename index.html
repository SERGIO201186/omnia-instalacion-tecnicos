✍️ Acta y firma del cliente

Al completar los pasos anteriores, pide al cliente que revise el avance y firme de aceptación. Esto genera el reporte que queda registrado para seguimiento.

Completa el ID de instalación, la app, el nombre del cliente y el técnico arriba para habilitar la firma.
